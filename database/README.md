# Database

- `prisma/`: schema, migrations and repeatable reference-data seed.
- `client/`: PostgreSQL/Prisma client setup and isolated-test safeguards.
- `scripts/`: local PostgreSQL startup, test migrations and isolated backup/restore drill.
- `tests/`: database integrity integration tests.
- `generated/`: ignored Prisma client generated by `npm run db:generate`.

Run database commands from the repository root. Root `prisma.config.ts` points here. Private local database files, recovery credentials and backups remain under ignored `.local/`; they are not disposable build files and must not be committed or deleted during cleanup.
